# Landing reservoir imagery — sources & usage basis

All files live in this folder (`frontend/public/landing/reservoirs/`) so the
hero crossfade uses **local, preloaded assets only** — no remote URLs at
runtime. Generic editorial labels only (HEAVY OIL ENVIRONMENT,
STEAM-ASSISTED RECOVERY, OIL PRODUCTION, RESERVOIR SYSTEM). **None of these
images depicts Baghewala Field** and none is labeled as such.
